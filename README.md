## ❓ Frequently Asked Questions

<details>
<summary><b>What type of free SSL do you provide?</b></summary>

Free SSL is provided via Let's Encrypt and can be issued in seconds with a single click.
</details>

<details>
<summary><b>Do you provide website migration?</b></summary>

Yes, free migration is available if your previous host used cPanel. Request it by creating a support ticket. For some plans, free migration applies to Small or higher packages ordered annually.
</details>

<details>
<summary><b>Can you install my web application for me?</b></summary>

Hosting is semi-managed, so installs aren't included by default, but you can hire a support agent to do it. Create a ticket for details.
</details>

<details>
<summary><b>How do I install web apps with one click?</b></summary>

On cPanel, use Softaculous: pick your application, fill in a few details, and proceed.
</details>

<details>
<summary><b>What does "semi-managed" support mean?</b></summary>

Agents will reply to your queries and help as much as possible, but won't perform actions on your behalf unless the issue is on Limitless Hosting's end. Managed support is available at extra cost.
</details>

<details>
<summary><b>Which control panel is used for DirectAdmin plans?</b></summary>

DirectAdmin, which offers most of the major features found in cPanel.
</details>

<details>
<summary><b>Do plans include a free domain?</b></summary>

No. Domains must be ordered separately.
</details>

<details>
<summary><b>Do you offer backups?</b></summary>

Remote backups powered by JetBackup with one-click restore are available on select hosting plans. Germany hosting currently has no remote backups, and VPS plans do not include backups, so please back up manually.
</details>

<details>
<summary><b>Are there hidden charges?</b></summary>

No hidden charges.
</details>

<details>
<summary><b>What is the refund policy?</b></summary>

Hosting plans come with a 15-day money-back guarantee. Blesta licenses are non-refundable. See the [Terms of Service](https://limitlesshost.net/terms-of-service/) for full details.
</details>
